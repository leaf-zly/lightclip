# Function And UI Audit (2026-09-07)

Scope: the current Tauri Windows host, shared renderer, runtime bridge, storage, updater, packaging configuration, and documentation. This is a source and regression audit, not a claim that every application or hardware configuration has been tested.

## Fixed During This Audit

- Settings now opens the same signed updater dialog as the title-bar action.
- Updater keyboard events stay inside the dialog. Focus is contained and restored on close.
- Download completion no longer unlocks the updater while installation is still running.
- Rechecking discards stale update metadata; copy-link failures no longer show false success.
- Preview and settings Enter keys no longer trigger unrelated history copies. IME composition is respected.
- Compact history has a per-record preview/actions button with pin and delete access.
- Preview pin state updates immediately. Long titles do not expand the dialog.
- Keyboard history selection scrolls into view; incremental captures no longer collapse the expanded list.
- Incremental native events include retained IDs, removing records evicted by retention and storage budgets.
- Explicit null correctly clears a temporary capture pause.
- Clipboard reads skip unchanged Windows clipboard sequence numbers, avoiding repeated PNG encoding and file helpers.
- State loading and history copying run off the UI thread. Paste input submission/failure events are wired to Tauri.
- Failed clipboard writes reopen the panel. Copy dispatch is guarded against concurrent activation.
- Failed deletes restore in-memory history and return an error.
- Storage relocation restores the previous directory on failure and uses unique probe files.
- Store and location-config replacement no longer delete a valid destination before rename.
- Budget cleanup serializes each candidate once instead of the whole store per eviction; pins remain protected.
- Text limits match the renderer's UTF-16 character count. Copy counters saturate rather than overflow.
- Invalid byte counts never display NaN. Today means the local calendar day.
- Dark accent text has improved contrast; scrollbars and small-window controls use shared styling.
- Privacy documentation now describes automatic update checks accurately.

## Reproducible Verification

- `pnpm build`: source integrity, TypeScript, Vue templates and renderer build.
- `pnpm test`: search, updater parsing/retry/progress, retention-event reconciliation and invalid byte counts.
- `cargo test --release --locked --lib --manifest-path src-tauri/Cargo.toml`: run in GitHub Windows CI because the local machine has no MSVC linker.
- `node scripts/test-renderer-ui.cjs`: requires Playwright (`PLAYWRIGHT_MODULE` may select an existing installation), plus Edge or an `AUDIT_BROWSER` channel. Optional `LIGHTCLIP_AUDIT_OUTPUT` saves screenshots.
- Browser audit uses 936 synthetic text/image/file records at 320/390/560/860 px in light and dark modes. It checks filter tooltips, image loading, keyboard isolation, preview pinning, focus containment, settings scrolling, updater routing and installation failure/close protection.
- Browser tests mock native APIs and update transfer. They do not modify clipboard history or install an update.

## Requirements Still Open

| Requirement | Actual implementation / remaining work |
| --- | --- |
| Persisted image thumbnails | Images still use their full PNG data URL; only browser loading is deferred. A thumbnail cache is not implemented. |
| Lazy startup payloads / full virtualization | Initial state still includes all records and image payloads; the list renders progressively in batches. |
| Edit before copy | Not implemented. |
| Filtered export | JSON export currently exports history without text-only, pinned-only or date-range selection. |
| Tauri account encryption | Unavailable and disabled in the UI. The old Electron runtime has a different encryption implementation. |
| All native maintenance operations remain responsive | Some less-frequent import/export/cleanup commands are still synchronous. A full storage worker and separate metadata persistence remain follow-up work. |
| Universal automatic paste | Native input submission can be checked, but does not prove a target editor accepted content. Real multi-monitor/DPI, elevated apps, browsers, terminals and office editors need a desktop acceptance matrix. |
| Full update installation | Renderer tests mock downloads/install failures. A real previous-version-to-new-version install needs a new release and desktop acceptance. |

Previous statements describing thumbnails and every extension as completed were too broad. The above gaps are not certified as done by this audit.

## Release Status

This audit does not create a new version tag or publish an installer. The existing GitHub workflow can build an unpublished package and run native shortcut/paste smoke tests separately from a public release.
